Cara kerjanya

Tidak ada yang diunggah ke server mana pun.

  1. Anda pilih satu klien dan satu portal

    Nama klien dan banknya saja. Tidak ada daftar akun, tidak ada password.

  2. Anda login sendiri

    Di browser Anda, di sesi screen-share 20 menit. Password dan OTP tidak pernah saya lihat atau minta.

  3. File dan buktinya masuk folder Anda

    Berserta satu baris untuk setiap file: ukuran, jenis, halaman, saldo akhir, dan nama bank.

Yang tidak pernah saya minta

Empat hal ini tidak keluar dari komputer Anda, dan tidak pernah saya minta.

  • Password atau kode OTP.
  • Akses ke akun Anda.
  • Perubahan apa pun di portal bank.
  • Pengunggah file ke server mana pun.

Portal asli belum pernah diuji bersama Anda. Kalau portal Anda belum bisa, saya sebutkan apa adanya dan tagihan Rp 0. Yang di luar pilot ini: rekapan dan jurnal.
