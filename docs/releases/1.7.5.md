# WHAT REACHED THE SURFACE

- **The loopback door now requires one token.** All POST endpoints (`/command`, `/prefer`, `/lease`, `/health`) read the same secret from `OPERA_BRIDGE_TOKEN` or `~/.navego/bridge-token`. Unauthenticated callers learn nothing beyond "something is linked". A page hosted on another site in the browser can no longer drive the browser.
- **CSP dropped the bare `https:` wildcard** — named hosts only now (Supabase).
- **Contract fixes:** `browser_open_url` never navigates an already-open tab; `until:'text'` honors `absent:true`; `until:'url'` actually waits for the URL; wait budgets respect documented caps; focusWindow answers state without moving the window; CDP frames no longer crash the local driver.
- **No more Hash/sign claims in update.html** — facts are honest.
- Pinned boundaries updated for the deliberate manifest/source changes.

# WHAT CHANGED FOR CALLERS

- No tool-name changes. Self-update now happens through the zip; the browser still checks every 30 minutes after the one folder allow.
- The local driver starts enforcing `bridge token` — any caller opening HTTP doors without it gets a 401.
- Read the caller-auth guide in `docs/security.md` for the threat model.

# WHAT IT COSTS THE READER

- This build is what you already pulled via self-update; if you were on 1.7.4 you now have 1.7.5.
- Shell commands run by the local drive are still OS-level; this is not a sandbox. The boundary that matters is: a page on the web, a local web process, or a dev server on another port — all denied.
