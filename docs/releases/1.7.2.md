# WHAT REACHED THE SURFACE

- **Satu nama produk: Navego.** Semua permukaan aktif — situs, manifes ekstensi (`name`/`short_name`/`default_title`), popup, `chrome.runtime` identity yang manusia baca, `serverInfo.name` MCP, dokumen, tes, dan pin di gate — kini bernama Navego. "Corbin" dan "Kemudi" tinggal di catatan sejarah (`docs/releases/**`, CHANGELOG, proof) yang tidak ditulis ulang.
- **Paket npm tetap `kemudi`** (plus alias `navego-mcp`) sebagai identitas internal yang sudah terpasang di mesin — tidak dipublikasikan ulang dengan nama baru. Perintah CLI tetap `kemudi`.
- **`navego-update` sudah live** dengan perbaikan `update.xml`: permintaan tanpa `?id=` kini menjawab satu entri `<app>` untuk setiap rilis aktif (legacy dan current), dan permintaan yang membawa `appid` di parameter `x` dibaca. Dipasang lewat run 43919875835.
- **Situs** mengklaim 45 tool di permukaan lokal (cabang ini membawa permukaan-45-tool + redesign yang sudah masuk ke main); bump ini memindahkan semua jam ke 1.7.2.

# WHAT CHANGED FOR CALLERS

- Agen yang membaca `serverInfo.name` sekarang melihat `navego`.
- Ekstensi dipasang menunjukkan **Navego** (bukan Kemudi) pada kartu browser dan popup.
- CLI tidak berubah: `kemudi doctor` (dan alias lama lainnya) bekerja seperti sebelumnya.

# WHAT IT COSTS THE READER

- Tidak ada izin baru. Setelah pemasangan sekali (atau update browser), tidak ada lagi langkah manual yang diminta.
- Pemasangan ekstensi di Windows non-enterprise tetap satu kali: seret `Navego-…-1.7.2.crx` ke halaman ekstensi. Browser tidak bisa meng-update CRX self-hosted secara otomatis di luar Web Store / domain enterprise — karena itu rilis berikutnya sebaiknya tidak menambah permukaan ekstensi.
