## The two funnel rows that counted page loads

The ticket `operator-to-marketer-20261126-1045.md` is answered by
`docs/agent-roles/queue/marketer-reply-20261126-2035.md`, and the work is pull
request https://github.com/afnannuzulasugihartono/navego/pull/472.

The instrument was wrong in two places. `install.view` was written inside the
page view, so the row counted a landing visit instead of a visitor who saw the
install command, and `pair.view` was written when the dashboard route mounted,
so a crawler probing `/dashboard` stood in for a person. The live funnel over
the last 24 hours held 33 anonymous browsers and 157 events, every row
anonymous, and 29 of those browsers on `/dashboard` — a path the anonymous
navigation does not link.

What the site does now:

- the page load writes `page.view` alone;
- the install command block writes `install.view` when it renders, with the
  surface it belongs to;
- the dashboard writes `pair.view` only when it found a session.
