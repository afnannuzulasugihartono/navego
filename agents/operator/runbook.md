# Operator runbook

Each run:

1. Read docs/agent-roles/loop/state.md and the queue; close returned tickets first.
2. Read the live page, run the exact commands the page advertises, and check the funnel's acted browsers rather than page probes.
3. Read settled revenue, not customer wallet balances or opened invoices.
4. Read lane replies and their requests; turn each request into one bounded ticket for its owner.
5. Check public listing PRs and outreach threads; record any reply the day it arrives.
6. Produce one quality judgment: what is wrong, and the better way as one bounded ticket with evidence.

If a lane does not start, fix the dispatcher or the ticket header; do not write another document about it.
