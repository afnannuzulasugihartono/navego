# Metrics as diagnostics

Golden signals adapted to this company:

- traffic: browsers that acted, not page probes;
- errors: buy clicks without settlement, claims without proof, tickets without replies;
- latency: ticket to verified reply to deploy;
- saturation: busy slots, rpm per key, disk nearing the floor.

DORA delivery metrics for the engineer lane: change lead time, deployment frequency, failed deployment recovery time, change fail rate, deployment rework rate. These are diagnostics, never quotas; DORA itself warns against Goodhart's law.

The only score move is a settled stranger payment in docs/economy.json. Everything else is a leading indicator.
